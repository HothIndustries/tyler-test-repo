# tyler-test-repo

## Cool Python Project: ASCII Mandelbrot

This repository now includes a small Python project that renders an ASCII
Mandelbrot fractal in the terminal.

### Run it

```bash
python3 /home/runner/work/tyler-test-repo/tyler-test-repo/mandelbrot.py
```

### Run tests

```bash
python3 -m unittest -v /home/runner/work/tyler-test-repo/tyler-test-repo/test_mandelbrot.py
```
